# LifeLoop

목표를 선행지표로, 선행지표를 루틴으로, 배운 것을 내 말로.

혼자 쓰는 설치형 웹앱(PWA)이다. **계정도 서버도 없다.** 모든 기록은 그 기기의
`localStorage` 안에만 있고 어디로도 전송되지 않는다.

## 왜 이렇게 만들었나

자기계발 앱이 실패하는 지점은 기능 부족이 아니다.

1. **입력 마찰** — 기록에 하루 10분이 들면 2주 안에 그만둔다. 그래서 일상 기록은 탭 한 번이다.
2. **"한 척"의 기록** — "3시간 공부함"은 공부했다는 증거가 아니다. 그래서 공부·독서
   세션에는 하루 한 개, 배운 것을 내 말로 설명한 파인만 노트를 남긴다.

## 구조

```
목표 (통제 못 함)      "에너지관리기사 실기 합격"     D-67
 └ 선행지표 (통제 함)   "주 5회 기출 세션"            ← 점수를 매기는 대상
    └ 루틴             "저녁 먹고 나면 → 기출 20문항"  (최소: 5문항)
       └ 세션          타이머 32분 / 탭 한 번
          └ 파인만 노트  "공기비가 크면 왜 손해인가"
             └ 구멍     "최적 공기비 계산이 막힘"      → 다음 세션 주제로 환류
                └ 복습  가린 채 다시 설명하기
```

구멍이 다시 세션으로 돌아오면서 고리가 닫힌다. 그게 이 앱의 전부다.

접목한 것: 구현 의도, 2분 규칙(최소 버전), never miss twice, don't break the chain,
4DX 선행지표, 파인만 기법, 인출 연습, 간격 반복, GTD 주간 회고.

뺀 것: 포인트·아바타 게이미피케이션, 리더보드, 소셜, AI 코치, 감정 일기, 푸시 알림.

## 쓰기

브라우저로 열고 홈 화면에 추가하면 끝이다. 설치 후에는 비행기 모드에서도 동작한다.

### 기출 문항 연결 (선택)

`노트 → 기출 문항 가져오기`에서 회차 JSON 파일을 고른다. 문항은 **이 기기에만**
저장되고 저장소에는 포함되지 않는다. 기대하는 형식:

```json
{
  "year": 2023, "round": 1,
  "questions": [
    { "id": "2023-1-01", "no": 1, "type": "계산", "topic": "연소",
      "question": "...", "given": ["..."], "answer": ["..."], "solution": "..." }
  ]
}
```

노트에는 문제 전문이 아니라 **출처만** 붙는다(`2023년 1회 2번 · 연소`).
공유할 때도 기본적으로 내 설명만 나간다 — 남의 문제를 퍼나르는 도구가 아니다.

## 개발

빌드 단계도 의존성도 없다. 정적 파일을 그대로 서빙하면 된다.

```sh
node selftest.mjs          # 자체 점검 26개
python -m http.server 8123 # 아무 정적 서버나
```

`selftest.mjs`는 날짜 계산, 간격 반복 사다리, 연속 기록/결석, 선행지표 집계,
문항 가져오기 검증, 공유 마크다운을 검사한다. 프레임워크는 쓰지 않는다.
